# Prompt: Documentation Update

Use when asked to bring documentation up to date with recent code changes.

---

Follow [`.agent/workflows/documentation.md`](../workflows/documentation.md): identify what changed (module boundary, decision, shipped feature, planned work), update the corresponding doc (`docs/ARCHITECTURE.md`, a new `docs/adr/`, `moon/CHANGELOG.md`, or `moon/roadmaps/*.md`), and verify code examples still match the current `app/` module before submitting.
