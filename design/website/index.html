C++ Class & Decision Architecture

High-performance gameplay ticks are coordinated through custom C++ classes extending the Unreal Engine 5 framework:

  • `AAISoccerPlayerAgent`: Extends `ACharacter`, manages attributes (stamina, positioning) and queries.
  • `AAISoccerAIController`: Runs the Behavior Tree execution loop.
