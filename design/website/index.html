The Sengoku Jidai & Yokai Corruption

Set in the 1520s, Mobile Fortress transports players to a historically inspired, mythological feudal Japan. Players do not just build stationary stone towers; they deploy ashigaru spearmen, matchlock gunners, and recruit legendary Samurai heroes to fight back invading hordes of Yokai.

The thematic aesthetic is rooted heavily in Ukiyo-e (woodblock print) art style. Bold inks, vintage paper textures, and dynamic water ripples create a tactile representation of classic Japanese prints.

"The environment itself reacts to purification. As you purge the Yokai defilement, the land shifts from monochromatic ash to vibrant, hand-painted watercolor."

Simulation Controls

In Mobile Fortress, enemies don't path individually. The map maintains a global Dijkstra grid and a normalized vector flow field. Placing a wall or blocker recalculates the flow for all units instantly.

Dijkstra Math: C(p) = min(C(n) + Cost)
Vector Gradient: V(p) = -∇C(p)

Imitation vs. Competition Agent

Rather than inflating health pools, Mobile Fortress uses a dual-agent Reinforcement Learning model to modulate challenge:

  • Imitation Agent (Clone): Tracks player placement velocity, response to breaches, and upgrade habits, learning to copy the player.
  • Competition Agent (Tactician): Searches for tactical counters to the clone's setup and adapts enemy wave mixtures dynamically.
