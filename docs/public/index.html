Wokou-Era Coastal Defense & Unit Class Design

Mobile Fortress merges cooperative 2D tower defense combat with a persistent 4X coastal territory map. Players deploy garrison spearmen, Fo-lang-ji cannon crews, Portuguese arquebusiers, war junks, and veteran commanders to repel Wokou pirate raiders by land and sea.

Flow Field Pathfinding: Recalculates cost vectors for all units simultaneously, bypassing standard pathfinding bottlenecks.

Headless Rust Core & FFI Architecture

The simulation engine is isolated within a headless Rust core compiled with FFI bindings using UniFFI.

  • `hecs` ECS Engine: contiguously packages components to maximize memory cache hits on mobile processors.
  • `rkyv` Serialization: generates zero-copy state buffers, bypassing dynamic language parsing overhead.

$$E = w_1 \cdot \text{EnemiesOnScreen} + w_2 \cdot \text{KeepHealthLoss} + w_3 \cdot \text{BossPresence}$$
