# stack/eslint/

ESLint configuration for the documentation website (React 19 + TypeScript).

| File | Role |
| --- | --- |
| `eslint.config.js` | Flat config (ESLint 9): TypeScript + JSX |

## Usage

From `docs/website/`:

```bash
npm run lint
# or
npx eslint -c stack/eslint/eslint.config.js .
```
